# Functional Requirements

## Todo Application

### FR-1: Edit a Todo
- The user can edit an existing todo item.
- The user can update the title/description of a todo.
- Changes are saved and reflected immediately in the todo list.

### FR-2: Sort Todos by Name
- The user can sort the todo list alphabetically by name.
- Sorting can be toggled between ascending (A–Z) and descending (Z–A) order.

### FR-3: Add a Due Date to a Todo
- The user can add a due date when creating or editing a todo item.
- The due date is displayed alongside the todo item in the list.
- The user can update or remove a due date from an existing todo.
